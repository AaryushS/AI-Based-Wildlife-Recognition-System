# AI Based Wildlife Recognition Project 🐾

This project identifies animals from images using a fine-tuned ResNet model.

## Technologies Used
- Python
- TensorFlow / Keras
- Flask
- HTML, CSS

## Project Structure
- `app2.py` – Main Flask application
- `dataset/` – Training dataset (not uploaded)
- `static/` – CSS and static files
- `templates/` – HTML files
- `results/` – Output results
- `confusion_matrix.png` – Model evaluation result

## Model File
The trained ResNet model (`.h5`) is not uploaded due to GitHub size limits.

## How to Run
```bash
pip install -r requirements.txt
python app2.py
